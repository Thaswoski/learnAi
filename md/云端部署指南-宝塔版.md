# 智多星 - 阿里云 + 宝塔面板部署指南

---

## 一、准备工作

### 1.1 打包本地文件

把整个项目文件夹打成 zip：

```
learnAi 文件夹 → 右键 → 压缩 → learnAi.zip
```

### 1.2 阿里云安全组开放端口

登录阿里云控制台 → 云服务器 ECS → 安全组 → 添加规则：

| 端口 | 用途 |
|------|------|
| 80 | 网站访问 |
| 443 | HTTPS（可选） |
| 8888 | 宝塔面板 |
| 3306 | MySQL（可选，仅本地访问就不开） |
| 6060 | Java 后端 |
| 5050 | Python 服务 |

### 1.3 连接到服务器

用 Xshell / FinalShell / PuTTY 连上你的阿里云服务器。

如果是第一次用，先装宝塔面板：

```bash
# CentOS
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh

# Ubuntu/Debian
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh
```

装完会显示宝塔面板的登录地址、用户名、密码，记下来。

---

## 二、宝塔面板安装环境

浏览器打开 `http://你的服务器IP:8888` 登录宝塔面板。

### 2.1 安装软件

宝塔面板 → 软件商店 → 搜索安装：

| 软件 | 说明 |
|------|------|
| MySQL 5.7 | 数据库 |
| Nginx 1.20+ | 网站服务器 |
| Java 项目一键部署 | 跑 JAR 包 |
| Python 项目管理器 | 跑 Python 服务 |

> 如果软件商店没有 "Java 项目一键部署"，没关系，后面用命令行跑也行。

### 2.2 安装 JDK（如果软件商店没有）

SSH 连上服务器：

```bash
# 安装 JDK 17
yum install -y java-17-openjdk java-17-openjdk-devel
# 验证
java -version
```

### 2.3 安装 Python 依赖

```bash
# 检查 Python 版本
python3 --version

# 安装 pip（如果没有）
yum install -y python3-pip
```

---

## 三、上传项目到服务器

### 3.1 上传

宝塔面板 → 文件 → 进入 `/www/wwwroot/`，新建文件夹 `learnAi`。

把 `learnAi.zip` 上传到这个目录，然后右键解压。

或者用 FinalShell/Xftp 直接拖进去。

### 3.2 目录结构

上传后服务器上的目录应该是：

```
/www/wwwroot/learnAi/
├── backend/
├── ppt-service/
├── frontend/
│   └── dist/
└── uploads/
```

---

## 四、数据库配置

### 4.1 创建数据库

宝塔面板 → 数据库 → 添加数据库：

| 参数 | 值 |
|------|------|
| 数据库名 | ai_learn |
| 用户名 | ai_learn |
| 密码 | 设一个复杂的密码 |
| 字符集 | utf8mb4 |

### 4.2 导入 SQL 文件

SSH 连上服务器：

```bash
cd /www/wwwroot/learnAi

# 按顺序导入
mysql -u ai_learn -p ai_learn < backend/src/main/resources/db/schema.sql
mysql -u ai_learn -p ai_learn < backend/src/main/resources/db/ai_learn.sql
mysql -u ai_learn -p ai_learn < backend/src/main/resources/db/chat_message.sql
mysql -u ai_learn -p ai_learn < backend/src/main/resources/db/community.sql
mysql -u ai_learn -p ai_learn < backend/src/main/resources/db/resource_record.sql
mysql -u ai_learn -p ai_learn < backend/src/main/resources/db/student_profile.sql
```

输入你刚设的数据库密码。

### 4.3 修改后端数据库连接

宝塔面板 → 文件 → 编辑 `/www/wwwroot/learnAi/backend/src/main/resources/application.yml`

找到这两行改成你刚设的：

```yaml
    username: ai_learn          # 改成你的数据库用户名
    password: 你设的密码          # 改成你的数据库密码
```

## 五、启动 Java 后端

### 5.1 先打包（在本地电脑打，然后上传 JAR）

在你本地电脑：

```powershell
cd d:\OTHERS\learnAi\backend
mvn clean package -DskipTests
```

打包完成后，把 `backend/target/learn-backend-1.0.0.jar` 上传到服务器 `/www/wwwroot/learnAi/backend/target/` 下。

### 5.2 在服务器启动

SSH 连上服务器：

```bash
cd /www/wwwroot/learnAi/backend
nohup java -jar target/learn-backend-1.0.0.jar > logs.log 2>&1 &
```

> 解释：`nohup` = 后台运行不挂断，`> logs.log 2>&1` = 日志写到文件，`&` = 后台

检查是否启动成功：

```bash
tail -f logs.log
```

看到 `Tomcat started on port 6060` 就成功了。

### 5.3 后端接口测试

浏览器访问：`http://你的服务器IP:6060/api/user/health`

---

## 六、启动 Python 服务

### 6.1 先装依赖

在服务器上：

```bash
cd /www/wwwroot/learnAi/ppt-service
pip3 install -r requirements.txt
```

> 如果慢加镜像：`pip3 install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/`

### 6.2 后台启动

```bash
cd /www/wwwroot/learnAi/ppt-service
nohup python3 main.py > logs.log 2>&1 &
```

检查：

```bash
tail -f logs.log
```

看到 `Uvicorn running on 0.0.0.0:5050` 就成功了。

## 七、部署前端 + 配置 Nginx

### 7.1 宝塔面板添加网站

宝塔面板 → 网站 → 添加站点：

| 参数 | 值 |
|------|------|
| 域名 | 你的域名 或 服务器IP |
| 根目录 | `/www/wwwroot/learnAi/frontend/dist` |
| PHP | 纯静态 |

### 7.2 配置 Nginx

宝塔面板 → 网站 → 点击你刚建的网站 → 配置文件，把内容改成：

```nginx
server {
    listen       80;
    server_name  你的域名或IP;
    
    # 前端静态文件
    location / {
        root   /www/wwwroot/learnAi/frontend/dist;
        index  index.html;
        try_files $uri $uri/ /index.html;
    }

    # Java 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:6060/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 30s;
        proxy_read_timeout 86400s;
    }

    # 上传文件
    location /uploads/ {
        alias /www/wwwroot/learnAi/uploads/;
    }

    # 禁止访问敏感文件
    location ~* (\.user.ini|\.htaccess|\.git|\.svn|\.DS_Store|node_modules|package.*\.json|\.log|\.sql|pom\.xml|application.*\.ya?ml)$ {
        return 404;
    }
}
```

保存后宝塔会自动重载 Nginx。

浏览器打开 `http://你的域名或IP`，能看到主页就成功了。

## 九、常用管理命令

```bash
# 查看 Java 后端进程
ps -ef | grep java

# 查看 Python 进程
ps -ef | grep python3

# 停止 Java 后端
kill -9 $(ps -ef | grep 'learn-backend' | grep -v grep | awk '{print $2}')

# 停止 Python 服务
kill -9 $(ps -ef | grep 'main.py' | grep -v grep | awk '{print $2}')

# 重新启动 Java
cd /www/wwwroot/learnAi/backend && nohup java -jar target/learn-backend-1.0.0.jar > logs.log 2>&1 &

# 重新启动 Python
cd /www/wwwroot/learnAi/ppt-service && nohup python3 main.py > logs.log 2>&1 &

# 重载 Nginx
nginx -s reload
```

## 十、注意事项

1. **阿里云安全组别忘了开端口**，这是新手最容易忘的
2. **数据库密码**记得改成你自己的，别用默认的 114514
3. **DeepSeek/通义千问/星火/豆包 API Key** 可能会过期或用完额度，到时候在 `application.yml` 里换新的，改完重新打包上传
4. 如果想绑定域名，在宝塔面板网站设置里改 `server_name`，然后去域名解析加一条 A 记录指向服务器 IP

## 总结：部署流程一张图

```
本地电脑                          阿里云服务器
─────────────────────────────────────────────
1. 打包 JAR                →
2. 打 zip 包                →    上传到 /www/wwwroot/learnAi/
                           
                            →    3. 宝塔装 MySQL/Nginx/JDK/Python
                            →    4. 创建数据库 ai_learn，导入 SQL
                            →    5. 改 application.yml 数据库密码
                            →    6. nohup java -jar ... &  启动后端
                            →    7. pip3 install & nohup python3 ... &  启动Python
                            →    8. 宝塔添加网站，配置 Nginx
                            →    9. 浏览器打开 → 搞定
```
