# 本地运行指南（无脑版）

## 你需要先装好的东西

1. **JDK 17** - 去 https://adoptium.net/ 下载安装
2. **Python 3.10+** - 去 https://www.python.org/ 下载，安装时勾上 "Add Python to PATH"
3. **MySQL** - 去 https://dev.mysql.com/downloads/mysql/ 下载安装
4. **Node.js** - 去 https://nodejs.org/ 下载 LTS 版安装

装完之后打开 PowerShell 验证一下：

```
java -version
python --version
mysql --version
node -v
npm -v
```

都能显示版本号就OK。

---

## 一、搞数据库

打开 PowerShell，登录 MySQL：

```
mysql -u root -p
```

输入你装 MySQL 时设的密码。然后敲：

```sql
CREATE DATABASE IF NOT EXISTS ai_learn DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

然后导入 SQL 文件（在项目 backend 文件夹里）：

```
cd 你项目的路径

mysql -u root -p ai_learn < backend\src\main\resources\db\ai_learn.sql


## 二、改数据库密码

打开 `backend\src\main\resources\application.yml`，找到这两行改成你自己的：

```yaml
    username: root              # 你的MySQL用户名
    password: 你的MySQL密码       # 你的MySQL密码
```

## 三、启动 Python 服务（PPT生成）

打开一个新 PowerShell：

```
cd 你项目的路径\ppt-service
pip install -r requirements.txt
python main.py
```

看到 `Uvicorn running on http://0.0.0.0:5050` 就行了，**这个窗口别关**。

## 四、启动 Java 后端

再开一个新 PowerShell：

```
cd 你项目的路径\backend
mvn clean package -DskipTests
java -jar target\learn-backend-1.0.0.jar
```

看到 `Tomcat started on port 6060` 就行了，**这个窗口也别关**。

## 五、启动前端

再开一个新 PowerShell：

```
cd 你项目的路径\frontend
npm install
npm run dev
```

看到 `http://localhost:5173` 就行了。

---

## 打开浏览器

访问：**http://localhost:5173**

---

## 总结：你需要同时开 3 个 PowerShell 窗口

| 窗口 | 跑的东西 | 命令 | 端口 |
|------|---------|------|------|
| 窗口1 | Python PPT服务 | `python main.py` | 5050 |
| 窗口2 | Java后端 | `java -jar target\learn-backend-1.0.0.jar` | 6060 |
| 窗口3 | Vue前端 | `npm run dev` | 5173 |

三个都跑起来，打开 http://localhost:5173 就行了。

MySQL 是后台服务，不用管，开机自启的。
